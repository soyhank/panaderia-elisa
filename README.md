# Elisa Sabor & Arte — Panadería y Pastelería

Sitio web one-page para la panadería-pastelería **Elisa Sabor & Arte** ("El arte de endulzar tu vida").
Construido con Astro + Tailwind CSS 4, desplegado en Vercel.

- Carta completa con precios y filtro por categoría
- Pedidos directos por WhatsApp (974276358)
- Galería de tortas personalizadas
- SEO: Open Graph, JSON-LD (Bakery), sitemap

## Desarrollo

```bash
npm install
npm run dev
npm run build
```

Contenido en `src/data/site.ts` y `src/data/products.ts`. Imágenes en `public/img` (WebP).
